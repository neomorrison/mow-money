# Mow Money

A lawn care empire game for the browser. Start with a push reel mower, a bicycle and $60. Knock on doors, haggle with homeowners, mow their lawns in 3D, upgrade to zero-turns and trucks, hire crews and managers, then sell the company for a legacy bonus.

Play: https://neomorrison.github.io/mow-money/

Design and math: [docs/DESIGN.md](docs/DESIGN.md). Code map: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```bash
npm install
npm run dev
```
